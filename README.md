# Mether - The Crystal Dimension Mod

A magical fantasy dimension mod for Minecraft 1.26.2 (Fabric) featuring 10 unique crystal types, 8 biomes, 7 bosses, and extensive progression.

## Features

### Crystal Types (10)
| Crystal | Color | Tier | Theme |
|---------|-------|------|-------|
| Luminite | White/Silver | 1 | Basic / Light |
| Rubicite | Red | 2 | Fire / Heat |
| Sapphirite | Blue | 2 | Water / Ice |
| Emerite | Green | 2 | Nature / Growth |
| Citrite | Yellow | 2 | Lightning / Speed |
| Amethine | Purple | 3 | Magic / Enchanting |
| Obsidite | Black | 3 | Shadow / Stealth |
| Celestite | Cyan | 3 | Sky / Flight |
| Pyrope | Orange | 3 | Energy / Power |
| Prismarite | Rainbow | 4 | All Combined |

### Equipment (4 Tiers)
- **Tier 1 - Luminite:** Basic crystal gear (Iron level)
- **Tier 2 - Elemental:** Rubicite, Sapphirite, Emerite, Citrite (Diamond level)
- **Tier 3 - Advanced:** Amethine, Obsidite, Celestite, Pyrope (Better than Diamond)
- **Tier 4 - Prismarite:** Ultimate gear combining all powers (Better than Netherite)

Each tier includes: Pickaxe, Axe, Shovel, Hoe, Sword, Helmet, Chestplate, Leggings, Boots

### Mobs (7 Regular + 7 Bosses)

**Passive:**
- Crystal Butterfly
- Lumina Sheep

**Hostile:**
- Crystal Golem
- Crystal Spider
- Shadow Wraith
- Crystal Mage
- Unstable Elemental (explodes on death)

**Bosses:**
| Boss | Crystal | Health |
|------|---------|--------|
| Luminarch | Luminite | 300 HP |
| Infernal Crystal Titan | Rubicite | 350 HP |
| Frost Crystal Leviathan | Sapphirite | 320 HP |
| Verdant Crystal Hydra | Emerite | 380 HP |
| Storm Crystal Dragon | Citrite | 300 HP |
| Void Crystal Serpent | Obsidite | 340 HP |
| Prismatic Overlord | Prismarite | 500 HP |

### Biomes (8)
1. **Crystal Plains** - Starting biome, peaceful
2. **Crimson Crystal Forest** - Red crystals, dangerous
3. **Frozen Crystal Tundra** - Blue ice crystals
4. **Verdant Crystal Grove** - Green nature crystals
5. **Stormpeak Mountains** - Yellow lightning crystals
6. **Amethyst Caverns** - Underground purple crystals
7. **Shadowlands** - Dark corrupted zone
8. **Celestial Floating Islands** - Rare sky biome

### Food Items
- Crystal Berries (Glowing effect)
- Glowing Mushroom (Night Vision)
- Crystal Honey (Regeneration)
- Crystal Apple (Absorption + Resistance)
- Luminite Fruit (Strong Regeneration)

### Special Items
- Crystal Resonator - Detects nearby crystals
- Crystal Compass - Points to structures
- Growth Catalyst - Speeds crystal growth
- Teleportation Crystal - Fast travel
- Crystal Lens - Enhanced vision
- Energy Cell - Stores crystal energy

## Crafting Stations
- **Crystal Altar** - Portal activation (overworld)
- **Crystal Forge** - Basic crystal crafting (Tier 1-2)
- **Crystal Infuser** - Magical item infusion

## Portal
Build a portal frame from Luminite Portal Blocks and activate it with a Crystal Key.

## Progression
1. Craft a Crystal Key in the overworld
2. Build a Crystal Altar portal frame
3. Activate the portal to enter Mether
4. Explore Crystal Plains and mine Luminite
5. Defeat the Luminarch to unlock Tier 2
6. Explore elemental biomes and defeat elemental bosses
7. Defeat the Prismatic Overlord for Tier 4 gear

## Installation
1. Install Fabric Loader for Minecraft 1.26.2
2. Install Fabric API
3. Place the Mether mod JAR in your `mods` folder
4. Launch Minecraft!

## Building from Source
```bash
git clone https://github.com/menearmenear/mether.git
cd mether
./gradlew build
```
